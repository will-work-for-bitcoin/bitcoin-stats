**Support this project:**

On-chain Bitcoin network statistics CLI - fees, mempool, blocks, hashrate, and more. Pure Python, no dependencies.

## Installation

```bash
git clone https://github.com/will-work-for-bitcoin/bitcoin-stats.git
cd bitcoin-stats
```

## Usage

```bash
python bitcoin_stats.py
python bitcoin_stats.py --help
```

## Features

- Pure Python 3.7+, zero dependencies
- JSON/CSV export support
- Beautiful terminal output
- Easy to extend and customize
